# 仮想通貨自動売買システム（Coincheck API）

取引所のAPIと連携し、市場価格およびスプレッド（売値と買値の価格差）をリアルタイムで取得・計算して自動売買を行うPythonスクリプトです。

## 開発の背景・目的
24時間365日稼働する仮想通貨市場において、感情を排除したルールベースの取引自動化と、API連携・例外処理・セキュリティ設計の実践を目的として開発しました。

## 主な機能・実装の工夫
* **スプレッドを考慮した利益判定ロジック**
  単なる表面価格の変動だけでなく、取引所特有のスプレッドコストを加味した上で実質的な期待利益を算出し、エントリーおよび決済の判定を行うロジックを実装しています。
* **セキュリティを意識した認証情報管理**
  APIキーおよびシークレットキーなどの機密情報をソースコードから分離し、環境変数（`.env`）経由で安全に読み込む設計としています。
* **API通信エラー・ネットワーク障害への耐性（例外処理）**
  通信タイムアウトやレート制限、予期せぬレスポンス異常が発生した際にもプログラムが即座に異常終了せず、安全にエラーログを記録して待機・リトライする例外処理を組み込んでいます。

## 使用技術
* **言語:** Python 3.x
* **API:** Coincheck REST API
* **主なライブラリ:** `requests` / `hmac` / `hashlib` / `python-dotenv`
